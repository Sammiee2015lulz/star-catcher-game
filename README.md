# 🌟 Star Catcher

A fun and cool browser game! Catch the glowing stars with your neon ship while avoiding deadly meteors.

## How to Play

1. Open `index.html` in your browser (or host on GitHub Pages).
2. Click **Start Game**.
3. Move with **Arrow Keys** or **A/D**, or just move your mouse.
4. Catch stars for points (+10 each).
5. Avoid meteors — they cost a life!
6. Survive as long as you can and beat your high score!

## Features

- Neon cyberpunk style
- Particle effects
- Local high score (saved in browser)
- Smooth controls (keyboard + mouse)
- Increasing challenge as you play

## Setup

Just clone the repo and open `index.html`. No dependencies needed — pure HTML, CSS, and JavaScript!

```bash
git clone https://github.com/Sammiee2015lulz/star-catcher-game.git
cd star-catcher-game
# Then open index.html in your browser
```

Enjoy catching stars! 🚀
